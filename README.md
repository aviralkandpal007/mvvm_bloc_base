# mvvm_bloc_base

A reusable Flutter starter project organized around MVVM and BLoC.

## Theme documentation

Theme structure, component inventory, light/dark mode usage, customization
guidance, and extension instructions are documented in
[`lib/theme/theme.md`](lib/theme/theme.md).

## Project setup

Install Flutter and the dependencies declared in `pubspec.yaml`, then run:

```sh
flutter pub get
flutter run
```

Run static analysis and tests with:

```sh
flutter analyze
flutter test
```

This repository is a common base for MVVM/BLoC Flutter projects. Feel free to
reuse it and contribute improvements.
